Раздел **Протоколы** держит протоколы, по которым клиенты заходят на ноды. Новое подключение добавляется кнопкой **Добавить** из пресета: ключи, пароли и сертификаты создаются сами, вам остаётся выбрать ноду и при желании порт.

:::caution[Протоколы с одним ключом]
Sudoku, Snell и Shadowsocks-2022 с методом ChaCha20 работают с одним ключом на всех. Нода не различает пользователей, поэтому на них нет учёта трафика, лимитов, привязки устройств и автоподбора. Отключённый или истёкший пользователь сохраняет доступ, пока ключ не сменится, а сменить его можно, только удалив и добавив подключение заново.

Shadowsocks-2022 с методами AES (по умолчанию `2022-blake3-aes-128-gcm`) даёт каждому клиенту свой ключ, и всё это на нём работает, как на VLESS.
:::

:::note[TLS в TLS]
У Trojan и у VLESS без Vision (REALITY XHTTP, gRPC и PQ, TLS XHTTP, TLS WebSocket и оба CDN) внутри TLS протокола идёт TLS сайтов, которые открывает клиент. По размерам первых пакетов DPI может заметить прокси. Vision и AnyTLS прячут этот рисунок: держите рядом протокол с одним из них. В списке пресетов такие протоколы помечены «TLS в TLS».
:::

## Настройки подключения

Кнопка **Настроить** открывает вкладки «Основное», «Маскировка» (только для XHTTP) и «Конфиг (YAML)».

- **Имя в подписке**: как подключение называется в приложениях.
- **Порт**. Для Hysteria2 можно указать диапазон, например `20000-30000`: клиенты прыгают между портами, и блокировать один порт бесполезно. Откройте весь диапазон по UDP в файрволе.
- **Сайт для маскировки (REALITY)**: по умолчанию `www.microsoft.com:443`. Кнопки «Проверить» и «Подобрать рядом с сервером» (ищет сайты в той же /24-сети, что и нода). Если у панели есть домен, можно выбрать свой домен. Если вместо имени указан IP, нужно поле «Домен сайта (SNI)».
- **Обфускация** для Hysteria2: Salamander или Gecko. Gecko режет рукопожатие QUIC на куски случайного размера с добивкой, против DPI, который узнаёт QUIC по размерам пакетов. Его получают только Clash-приложения на mihomo 1.19.26+, поэтому держите рядом обычный Hysteria2.
- **Отпечаток TLS**: как в настройках (по умолчанию Chrome), Chrome, Firefox, Safari, iOS, Android, Edge, 360, QQ, случайный браузер или «Своё…» с любым именем профиля uTLS, например `chrome120`. Общее значение задаётся в **Настройки → Подписка**. У Hysteria2 и TUIC отпечатка нет.
- **Выход в интернет**: напрямую, [WARP](/mikan/nodes/warp/) или [через ноду](/mikan/nodes/cascades/).
- **Группа серверов**: группа решает, какой трафик тратит протокол: основной, свой лимит, без лимита или не входит в тариф. Протокол без группы тратит основной трафик. См. [Группы серверов и пакеты трафика](/mikan/billing/pools/).
- **В автовыборе** (с версии 0.5.2.1): выключите, если приложения не должны выбирать этот протокол сами. Он пропадает из «Авто» подписки и остаётся в списке и в группе своей страны. Для всей ноды есть такой же переключатель, см. [В автовыборе](/mikan/nodes/nodes/#в-автовыборе).
- **За прокси (nginx, HAProxy)**: см. [Подключение за прокси](/mikan/protocols/behind-proxy/).
- **За CDN** (с версии 0.5.2.0): адрес CDN для клиентов и настоящий IP клиента из заголовка, только для VLESS и Trojan на сертификате ноды поверх XHTTP, WebSocket и gRPC, см. [За CDN](/mikan/protocols/cdn/).
- **Через общий 443** (с версии 0.5.2.0): протокол делит порт 443 ноды с другими по имени TLS, см. [Общий порт 443](/mikan/nodes/shared-443/).
- **Автоподбор**: переключатели переноса порта и смены сайта, см. [Автоподбор](/mikan/protocols/autotune/).

## Копирование протокола

:::note[С версии 0.5.2.0]
Копирование появилось в 0.5.2.0.
:::

Кнопка **Копировать** в строке протокола делает ещё один такой же: те же настройки, но свои ключи, и клиенты получают копию как ещё одно подключение. В окне выберите:

- **На какую ноду**: на ту же или на другую. Копия на той же ноде слушает другой порт.
- **Порт**: пусто значит тот же порт, а если он занят, первый свободный.
- **Сайт для маскировки**, если это REALITY: оставьте как есть или выберите другой.

Адрес для клиентов, CDN и путь копируются как есть. Если у другой ноды они свои, поправьте их в настройках копии.

## Выход в интернет для нескольких протоколов

:::note[С версии 0.5.2.0]
Групповой выход появился в 0.5.2.0.
:::

Отметьте галочками несколько протоколов в списке (или «Выбрать все»), и над списком появится кнопка **Выход в интернет**. Она задаёт выход сразу всем отмеченным:

- **Напрямую**: сайты видят IP сервера;
- **Через WARP своей ноды**: у ноды должен быть настроен [WARP](/mikan/nodes/warp/);
- **Через ноду**: выберите другую ноду, см. [Каскады](/mikan/nodes/cascades/).

Это то же поле «Выход в интернет» из настроек протокола, только для многих протоколов за один раз.

## Свой конфиг

Пресет «Свой конфиг» открывает редактор YAML со слушателем mihomo типа vless, trojan, hysteria2, tuic или anytls. Имя, порт, адрес, пользователей и сертификат mikan подставит сам. Кнопка «Проверить» проверяет конфиг до сохранения.

:::note[VMess убран]
С версии 0.5.2.0 на нодах работает ядро Citrus, и VMess в нём нет. Подключения VMess, которые были раньше, при обновлении становятся VLESS с тем же транспортом и теми же пользователями. Клиенты получат новые ключи со следующим обновлением подписки.
:::

## Из командной строки

```bash
mikan inbound list
mikan inbound add                        # покажет список пресетов
mikan inbound add hysteria2 --port 20000-20100 --node 2
mikan inbound set vless-xhttp --port 2443
```

На сервере панели новый порт сам откроется в ufw, нода получит изменения за 30 секунд.

## Сайты для маскировки из командной строки

```bash
mikan targets scan                       # найти подходящие сайты рядом с сервером
mikan targets check --dest www.example.com:443
mikan targets apply --dest www.example.com:443 --all
```
