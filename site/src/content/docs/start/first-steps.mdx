## Вход

Ссылка на админку выглядит так:

```text
https://vpn.example.com:PORT/секретный-путь/
```

Порт случайный, путь из 24 символов. Любой другой путь на этом порту отвечает пустым «404 Not Found», поэтому без ссылки панель не найти. Логин и пароль показывает установщик. Если ссылка потерялась, на сервере:

```bash
mikan url
```

## Защитите вход

Откройте **Настройки → Безопасность**:

- **Двухфакторная защита**: кнопка «Включить 2FA», QR-код для Google Authenticator, 1Password или Aegis. Сохраните коды восстановления, второй раз их не покажут.
- **Ссылка на панель**: «Выдать новую ссылку», если старая могла утечь.
- Пароль меняется там же, длина от 12 символов.

## Подключения по умолчанию

На свежей установке уже есть четыре подключения (раздел **Подключения**):

| Подключение | Порт | Зачем |
|---|---|---|
| VLESS · REALITY · XHTTP | 443/tcp | основное для России: похоже на обычный HTTPS |
| Hysteria2 | 443/udp | быстрый протокол на QUIC |
| TUIC v5 | 8443/udp | ещё один QUIC-протокол |
| VLESS · REALITY · Vision | 8443/tcp | для старых клиентов без XHTTP |

Каждое можно включить, выключить, настроить или удалить. Новое добавляется кнопкой **Добавить**: выберите пресет, при желании поменяйте порт, ключи создадутся сами. Про все пресеты и настройки читайте в разделе [Пресеты протоколов](/mikan/protocols/presets/).

:::note
Смена порта или маскировки переподключает клиентов этого протокола на несколько секунд. Клиенты получают изменения со следующим обновлением подписки, приложения делают это раз в час.
:::

## Первый пользователь

<Steps>

1. Откройте **Тарифы** и поправьте тариф под себя: трафик за период, срок, число устройств, когда обнулять трафик. Подробнее в разделе [Тарифы и пользователи](/mikan/billing/plans/).

2. В **Пользователях** нажмите «Новый пользователь», укажите имя, при желании контакт, выберите тариф.

3. Кнопка «Создать и скопировать ссылку» создаёт пользователя и копирует ссылку на подписку.

4. Отправьте ссылку человеку. Открыв её в браузере, он увидит страницу подписки с кнопками для своих приложений.

</Steps>

## Если потеряли доступ

| Что случилось | Команда на сервере |
|---|---|
| нет ссылки на панель | `mikan url` |
| забыли пароль | `mikan reset-password`: новый пароль, все сессии, API-ключи и ключи доступа (passkey) отзываются |
| ссылка могла утечь | `mikan reset-path`: новая ссылка, старая перестаёт работать через несколько секунд |
| потерян телефон с 2FA | код восстановления при входе или `mikan disable-2fa` |
