---
title: Команда mikan
description: Справочник по команде управления сервером mikan.
---

Команда `mikan` без аргументов открывает меню в терминале: состояние, обновления, логи, доступ, сайты REALITY, ноды, бэкапы. Те же действия доступны командами. Сами команды на английском, запускаются от root.

## Сервер

| Команда | Что делает |
|---|---|
| `mikan status` | контейнеры, процессор и память, состояние панели, доступное обновление |
| `mikan doctor` | проверить сервер панели или ноды, у каждой строки подсказка, см. ниже |
| `mikan logs [panel\|node]` | логи в реальном времени, <kbd>Ctrl</kbd>+<kbd>C</kbd> останавливает |
| `mikan restart` | перезапустить контейнеры |
| `mikan update [--check]` | обновить сейчас, сначала бэкап, при сбое откат. `--check` только проверяет |
| `mikan install [флаги]` | установка, на установленном сервере открывает меню |
| `mikan uninstall [-y]` | остановить и удалить команду, данные остаются в `/opt/mikan` |

`mikan doctor` работает на сервере панели и на сервере ноды. Проверяет Docker и контейнеры, что порты слушаются, правила ufw для порта API ноды, порта панели и портов протоколов, синхронизацию времени (`timedatectl` и заголовок Date от github.com, допуск 30 секунд), DNS, выход по HTTPS на github.com и ghcr.io (нужны для обновлений), диск (✗ меньше 500 МиБ, ! меньше 2 ГиБ) и память. На ноде ещё раз отправляет «приветствие» панели и печатает результат. Каждая строка помечена ✓, ! или ✗ и содержит подсказку; если есть ✗, команда завершается с ненулевым кодом. `mikan status` сам предложит `mikan doctor`, когда что-то не так. Это инструмент для случая, когда панель не может достучаться до ноды совсем. Тот же набор проверок для сервера панели есть в самой панели: кнопка «Проверить сервер» в **Настройки → Система**.

## Доступ

| Команда | Что делает |
|---|---|
| `mikan url` | ссылка на панель и логин |
| `mikan reset-password` | новый пароль администратора, все сессии и API-ключи отзываются |
| `mikan reset-path` | новая секретная ссылка, старая перестаёт работать |
| `mikan disable-2fa` | выключить 2FA, если потерян телефон |

## Бэкапы

| Команда | Что делает |
|---|---|
| `mikan backup` | бэкап в `/opt/mikan/backups` |
| `mikan restore FILE [-y] [--no-db-snapshot]` | восстановить из бэкапа, см. [Бэкапы](/mikan/operations/backups/) |

## Ноды и подключения

| Команда | Что делает |
|---|---|
| `mikan node list` | ноды панели |
| `mikan node add --name NAME --host IP [--domain D] [--api-port P]` | добавить ноду и получить ключ |
| `mikan node key NODE` | новый ключ ноды, старый перестаёт работать |
| `mikan node set NODE [--name] [--host] [--domain] [--enabled=true\|false]` | изменить ноду |
| `mikan join [KEY] [--panel-ip IP]` | на ноде: принять новый ключ из панели |
| `mikan inbound list` | подключения |
| `mikan inbound add PRESET [--port PORT] [--node N]` | добавить подключение, без пресета покажет список |
| `mikan inbound set NAME --port PORT [--node N]` | сменить порт, ключи и маскировка остаются |

Своя нода панели имеет номер 1, её адрес и домен меняются в настройках панели.

## Сертификаты

| Команда | Что делает |
|---|---|
| `mikan cert set --cert fullchain.pem --key privkey.pem [--node N]` | свой сертификат панели или ноды |
| `mikan cert show [--node N]` | что стоит сейчас |
| `mikan cert clear [--node N]` | вернуть Let's Encrypt (для ноды: самоподписанный) |

## Сайты маскировки REALITY

| Команда | Что делает |
|---|---|
| `mikan targets scan [--node N] [--json]` | найти подходящие сайты рядом с сервером |
| `mikan targets check --dest HOST:PORT [--sni NAME]` | проверить сайт |
| `mikan targets apply --dest HOST:PORT [--sni NAME] (--all \| --inbound NAME) [--force]` | поставить сайт всем подключениям или одному |

Для IP-адреса в `--dest` нужен `--sni`. Сайт проверяется перед применением, `--force` пропускает проверку.

## Адаптеры оплаты

| Команда | Что делает |
|---|---|
| `mikan addon list` | что работает и что есть в каталоге |
| `mikan addon install ID` | поставить или обновить адаптер |
| `mikan addon remove ID` | остановить и удалить, настройки и платежи в панели остаются |
