У Happ в **Настройки → Подписка** своя карточка. Её заголовки получает только Happ, остальные приложения их не видят. Сами заголовки описаны в [Спецификации подписки](/mikan/subscriptions/spec/#happ-и-incy).

## Шифрованная ссылка

**Шифрованная ссылка** прячет адрес подписки: вместо него у пользователя будет `happ://crypt5/…`. Её открывает кнопка Happ на странице подписки, она же показана в карточке пользователя как «Ссылка для Happ».

- **Выключена**: обычная ссылка `happ://add/…`.
- **Через Happ**: адрес один раз отправляется на crypto.happ.su. Если сервис недоступен, панель зашифрует сама.
- **Панель сама**: шифрует локально.

Перевыпуск ссылки пользователя делает недействительной и его шифрованную ссылку.

## Профиль маршрутизации

Поле **Профиль маршрутизации** принимает ссылку, собранную в самом Happ (Маршрутизация → Поделиться):

- `happ://routing/onadd/…`: добавить профиль и включить;
- `happ://routing/add/…`: только добавить;
- `happ://routing/off`: выключить маршрутизацию.

Happ добавляет профиль вместе с подпиской и применяет его после переподключения.

INCY получает тот же профиль. С конфигами Xray выбирайте «Из настроек маршрутизации»: этот профиль загружает geo-файлы, на которые ссылаются конфиги, и INCY берёт их целиком. Свой профиль для INCY собирайте без обрезки geo-файлов: если в обрезанном файле нет категории, на которую ссылается конфиг, INCY не запустит этот конфиг.

## Скрытые настройки серверов

- **Provider ID** с сайта happ-proxy.com: латиница, цифры, `-` и `_`, до 64 символов.
- **Скрыть настройки серверов**: пользователь не увидит параметры серверов в Happ. Работает только с сохранённым Provider ID.

:::note[С версии 0.5.2.1]
При включённом переключателе **Конфиги Xray для Happ и INCY** (**Настройки → Подписка → Приложения**, по умолчанию включён) Happ получает маршруты из **Настройки → Маршрутизация**, DNS и автовыбор внутри своих конфигов, см. [формат Xray](/mikan/subscriptions/spec/#формат-xray). При выключенном Happ получает ссылки, и эти маршруты до него не доходят: используйте профиль маршрутизации.
:::
